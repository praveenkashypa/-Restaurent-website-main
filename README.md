# 🍽️ Restaurant Website

Welcome to the **Restaurant Website** repository! This is a modern, visually appealing, and responsive front-end web application designed to showcase a restaurant's menu, ambiance, and services.

🌐 **Live Demo:** [View Website Here](https://resturnet.netlify.app/)

## 📖 About the Project
This project is built to provide a seamless browsing experience for food lovers. It features an intuitive user interface where visitors can easily explore delicious menu items, check out the restaurant's specialties, and get in touch for reservations or orders. 

## ✨ Features
* **Modern UI/UX:** A clean, appetizing, and user-friendly design.
* **Fully Responsive:** Works perfectly on desktops, tablets, and mobile phones.
* **Menu Showcase:** Beautifully organized sections highlighting food categories and popular dishes.
* **Fast Performance:** Lightweight and optimized for quick loading speeds via Netlify.
